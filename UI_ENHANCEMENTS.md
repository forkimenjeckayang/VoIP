1. **Gradients** - Used throughout for depth and visual interest
2. **Glassmorphism** - Profile header and balance card
3. **Micro-animations** - Hover states, pulse effects
4. **Card elevation** - Shadow and lift on hover
5. **Color coding** - Each stat has its own gradient
6. **White space** - Better spacing throughout
7. **Typography hierarchy** - Clear visual structure
